# 🎓 Student Grade Predictor

A simple and interactive **Student Grade Predictor** built using **HTML, CSS, and JavaScript**.

This project is created as part of the **CS302JSC — JavaScript Practical Lab** for **BCA/BIT Semester 5** at **Dev Sanskriti Vishwavidyalaya**.

---

## 📌 Project Overview

The Student Grade Predictor allows students to enter their personal details and marks in different subjects.

The application automatically calculates:

- Total marks
- Average percentage
- Final grade
- Pass/Fail status
- JavaScript data types using `typeof`

The project demonstrates important JavaScript concepts such as:

- Variables
- Data Types
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- Ternary Operators
- Nested Ternary Operators
- DOM Manipulation
- Functions
- Input Validation
